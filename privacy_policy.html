개인정보처리방침

앱명: WordSEN  |  시행일: 2026년 6월 11일  |  최종 수정일: 2026년 6월 11일

요약: WordSEN은 사용자의 개인정보(이름, 이메일, 위치 등)를 수집하거나 외부 서버에 저장하지 않습니다. 모든 학습 데이터는 사용자의 기기에만 저장됩니다.

1. 수집하는 개인정보

WordSEN은 어떠한 개인 식별 정보도 수집하지 않습니다. 구체적으로 다음 정보를 수집하지 않습니다.

  • 이름, 이메일 주소, 전화번호 등 연락처 정보
  • 위치 정보
  • 기기 고유 식별자
  • 사용 통계 또는 분석 데이터
  • 결제 정보

2. 앱이 저장하는 데이터

WordSEN은 다음 데이터를 사용자 기기 내부에만 저장합니다.

  • 사용자가 직접 입력하거나 편집한 단어 목록 및 폴더 구조
  • 학습 진행 상태(암기 여부, 학습 기록)
  • 앱 설정값(글꼴 크기, 언어, TTS 설정 등)

이 데이터는 앱 삭제 시 함께 삭제되며, 제3자에게 전송되지 않습니다.

3. 인터넷 사용 목적

WordSEN은 아래의 제한된 목적으로만 인터넷을 사용합니다.

  • TTS(음성 읽기): 단어 발음 제공을 위해 Google의 TTS API를 호출합니다. 이 과정에서 읽어야 할 단어 텍스트가 Google 서버로 전송될 수 있습니다. 별도의 사용자 개인정보는 포함되지 않습니다.
  • Daily 학습 콘텐츠: 매일 업데이트되는 학습 콘텐츠를 GitHub 서버에서 내려받습니다. 이 과정에서 사용자 정보는 전송되지 않습니다.

4. 제3자 서비스

WordSEN은 아래 제3자 서비스를 활용하며, 각 서비스의 개인정보처리방침이 별도로 적용됩니다.

  • Google TTS: https://policies.google.com/privacy
  • GitHub: GitHub Privacy Statement

5. 앱 권한

WordSEN이 사용하는 Android 권한과 그 목적은 다음과 같습니다.

  • INTERNET: TTS 음성 재생, Daily 콘텐츠 다운로드에 필요합니다.

위치, 카메라, 마이크, 연락처 등 민감한 권한은 사용하지 않습니다.

6. 어린이 개인정보 보호

WordSEN은 만 14세 미만 어린이를 대상으로 개인정보를 수집하지 않으며, 해당 연령의 사용자로부터 의도적으로 개인정보를 수집하지 않습니다. 본 앱은 개인정보를 수집하지 않으므로 어린이도 안전하게 사용할 수 있습니다.

7. 데이터 보안

모든 학습 데이터는 기기 로컬에만 저장되며 외부로 전송되지 않으므로, 서버 측 데이터 유출 위험이 없습니다. 기기 자체의 보안(잠금 화면, 암호화)은 사용자의 기기 설정에 따릅니다.

8. 개인정보처리방침의 변경

본 방침은 필요에 따라 변경될 수 있습니다. 중요한 변경이 있을 경우 앱 업데이트 노트 또는 본 페이지를 통해 안내합니다. 변경된 방침은 본 페이지에 게시된 날부터 효력이 발생합니다.
